# 🐺 The Wolf — Golf Tracker

## Deploy to Netlify (recommended, free)

1. Go to [netlify.com](https://netlify.com) and create a free account
2. Click **"Add new site" → "Import an existing project"**
3. Connect your GitHub account and push this folder to a new repo, OR
4. **Easiest:** Drag and drop this entire `wolf-golf` folder onto the Netlify dashboard

That's it — you'll get a live URL like `wolf-golf.netlify.app` in seconds.

---

## Deploy to Vercel (also free)

1. Go to [vercel.com](https://vercel.com) and create a free account
2. Click **"Add New Project"**
3. Import this folder from GitHub, or use the Vercel CLI:

```bash
npm i -g vercel
cd wolf-golf
vercel
```

---

## Run locally

```bash
npm install
npm run dev
```
